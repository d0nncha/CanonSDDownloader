# SD Photos Downloader

SD Photos Downloader — это консольное приложение на .NET 7, которое автоматизирует выгрузку фотографий с SD‑карты (или любой другой директории) в локальное хранилище. Утилита анализирует исходную структуру каталогов, группирует файлы по дате создания и копирует их в целевую папку, следя за свободным местом и обработкой дубликатов.

## Возможности

- Рекурсивный обход исходной директории с фильтрацией по дате создания файла.
- Формирование каталогов назначения по шаблону `yyyy_MM_dd` на основе даты создания снимков.
- Проверка объёма свободного места на целевом накопителе до начала копирования.
- Поддержка пропуска или перезаписи уже существующих файлов.
- Индикатор прогресса с количеством обработанных, скопированных, пропущенных и перезаписанных файлов.

## Требования

- [.NET SDK 7.0](https://dotnet.microsoft.com/download) или новее.
- Доступ к исходной директории (например, смонтированной SD‑карте) и правам записи в директорию назначения.

## Установка и сборка

```bash
git clone https://github.com/<your-account>/CanonSDDownloader.git
cd CanonSDDownloader/SDPhotosDownloader
dotnet restore
dotnet build --configuration Release
```

Собранный исполняемый файл будет находиться в `bin/Release/net7.0/`.

## Использование

Запустите программу командой:

```bash
dotnet run --project SDPhotosDownloader \
  --src "/media/user/SD_CARD/DCIM" \
  --dest "/home/user/Pictures" \
  --date "2023-07-01" \
  --overwrite false
```

Параметры командной строки:

| Опция | Обязательность | Описание |
|-------|----------------|----------|
| `--src <path>` | обязательная | Путь к директории, содержащей исходные фотографии. |
| `--dest <path>` | необязательная | Корневая директория, куда будут скопированы файлы. По умолчанию совпадает с текущей директорией запуска. |
| `--date <yyyy-MM-dd>` | необязательная | Минимальная дата создания файла. Файлы, созданные раньше, игнорируются. Значение по умолчанию — минимально возможная дата (`0001-01-01`). |
| `--overwrite` | необязательная | Флаг, управляющий перезаписью существующих файлов. По умолчанию `false`, то есть файлы с таким же именем будут пропущены. |

### Пример сценария

1. SD-карта смонтирована как `/media/user/SD_CARD`.
2. Необходимо скопировать все RAW-файлы, созданные начиная с 1 мая 2023 года, в каталог `~/PhotoArchive`.
3. При повторном запуске нужно перезаписывать совпадающие файлы.

Команда:

```bash
dotnet run --project SDPhotosDownloader \
  --src "/media/user/SD_CARD/DCIM" \
  --dest "$HOME/PhotoArchive" \
  --date "2023-05-01" \
  --overwrite true
```

## Внутреннее устройство

Приложение состоит из нескольких основных компонентов:

- **`Program.cs`** — точка входа. Создаёт корневую команду `System.CommandLine`, регистрирует параметры из `CLOptions`, создаёт экземпляры сервисов и вызывает `DownloadService.Start()`.

- **`CLOptions.cs`** — определяет параметры командной строки:
  - `--src` — путь к исходной директории
  - `--dest` — путь к директории назначения
  - `--date` — минимальная дата для фильтрации файлов
  - `--overwrite` — флаг перезаписи файлов

- **`DownloadService.cs`** — ядро приложения. Координирует работу сканирования, проверки места и копирования. Основные шаги:
  1. Выводит параметры работы в консоль.
  2. Сканирование исходного каталога методом `DirectoryScanner.Scan()`, который собирает файлы, прошедшие фильтр по дате, и группирует их по дню создания в формате `yyyy_MM_dd`.
  3. Проверка свободного пространства на целевом диске (`DirectoryScanner.GetDestinationFreeSpace()`).
  4. Если места недостаточно, приложение завершается с кодом `0`.
  5. Копирование файлов методом `Download()`, который создаёт каталоги по датам и копирует файлы с префиксом времени создания `yyMMddHHmmss_`, отслеживая прогресс.
  6. Вывод итоговой статистики.

- **`DirectoryScanner.cs`** — сканирует исходную директорию и получает информацию о свободном месте:
  - `Scan(string rootPath, DateTime dateFrom)` — рекурсивно обходит директорию, фильтрует файлы по дате и группирует их по дате создания.
  - `GetDestinationFreeSpace(string path)` — возвращает свободное место на диске в МБ.

- **`DownloadResult.cs`** — модель с итоговой статистикой:
  - `TotalProcessed` — всего обработано файлов
  - `TotalDownloaded` — успешно скопировано файлов
  - `Skipped` — пропущено существующих файлов
  - `Overwritten` — перезаписано файлов

- **`FileSystemAdapter.cs`** — адаптер для работы с файловой системой (реализует `IFileSystem`).

- **`ConsoleWriter.cs`** — сервис для вывода информации в консоль (реализует `IConsoleWriter`).

- **`DownloadOptions.cs`** — модель с параметрами загрузки (реализует `IDownloadOptions`).

- **`ScanResult.cs`** — модель с результатами сканирования (реализует `IScanResult`), содержит:
  - `Groups` — файлы, сгруппированные по дате создания
  - `FilesCount` — количество найденных файлов
  - `TotalSizeMb` — общий размер файлов в МБ

- **`FileEntry.cs`** — модель, представляющая информацию о файле (имя, путь, дата создания, размер).

## Обработка ошибок и ограничения

- Если свободного места недостаточно для полного копирования, приложение завершает работу до начала копирования и информирует об этом в консоли.
- При ошибках доступа к файлам/директориям сообщение с описанием исключения выводится в консоль, после чего обработка продолжается для остальных путей.
- Фильтрация по дате основана на метаданных файловой системы (`CreationTime`); при копировании между различными ОС возможны расхождения.
- Копируемым файлам добавляется префикс вида yyMMddHHmmss_ для избежания конфликтов имён и соблюдения правильной очередноти.
